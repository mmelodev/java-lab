## 🎯 Sobre

Hub de **estudos, exercícios e projetos** da linguagem Java. Aqui você encontrará desde conceitos básicos até implementações mais avançadas, organizados de forma didática.

## 📁 Estrutura do Repositório

O repositório está organizado nas seguintes pastas, cada uma com um propósito específico:

- **`EstudosAprofundados`**: Contém projetos e desafios com foco na maior complexidade em Java (Backend e Full-Stack), incluindo aplicações com **Spring Framework** e consumo de APIs.
- **`ExercíciosRandom/`**: Exercícios acadêmicos de lógica e fundamentos de Java.
- **`MiniProjetosPOO/`**: Pequenas aplicações práticas para exercitar a Programação Orientada a Objetos.

## 📚 Tópicos Estudados

### 🟢 **Fundamentos**
- ✅ Sintaxe básica e estruturas de controle
- ✅ Variáveis, tipos de dados e operadores
- ✅ Arrays e manipulação de strings
- ✅ Métodos e parâmetros
- ✅ Estruturas condicionais e loops

### 🟡 **Orientação a Objetos**
- ✅ Classes, objetos e construtores
- ✅ Encapsulamento e modificadores de acesso
- ✅ Herança e polimorfismo
- ✅ Interfaces e classes abstratas
- ✅ Tratamento de exceções

### 🔴 **Conceitos Avançados**
- ✅ Collections Framework (List, Set, Map)
- ✅ Streams API e expressões lambda
- ✅ Programação concorrente (Threads)
- ⏳ I/O e manipulação de arquivos
- ⏳ Testes unitários com JUnit
- ⏳ Boas práticas de segurança 

## 💻 Como Executar

### Pré-requisitos
- Java 8+ instalado
- IDE de sua preferência (IntelliJ IDEA, Eclipse, VS Code)

### Executando os projetos

# Clone o repositório
git clone https://github.com/mmelodev/java-lab.git

# Para arquivos .java simples
javac NomeDoArquivo.java
java NomeDoArquivo
